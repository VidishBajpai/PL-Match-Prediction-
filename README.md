# Premier League Match Prediction

A machine learning project that predicts Premier League match outcomes
(Home Win / Draw / Away Win) using historical match statistics.

## Features Used
- Home team form (last 5 games)
- Away team form (last 5 games)
- Average goals scored/conceded
- Goal difference
- Home/Away strength
- Points per game

## Models Used
- Logistic Regression
- XGBoost

## Accuracy
- Logistic Regression: ~47%
- XGBoost: ~47%

## Tech Stack
- Python
- Pandas
- Scikit-learn
- XGBoost
